# REAL 备课搭子 ｜ 中小学教师备课提示词生成器（适配体制内学校+国家课程及各版本教材）

> 你动嘴，我跑腿——把老师的专业判断，变成 AI 能听懂的"工作交接单"。

一个**单文件、零依赖、完全离线**的网页工具：老师不用学提示词工程，只需跟着页面作 8 组专业选择，即可自动生成一条结构完整的 **REAL 备课提示词**，复制到任意大模型（DeepSeek / Kimi / 通义千问 / 豆包等）就能获得贴合本班学情的教学设计初稿。

---

## 为什么做这个工具

直接把"帮我备一节课"丢给 AI，就像往同事桌上放一张便签——同事不是不努力，而是不知道面对哪个班、学生卡在哪里、这节课重点研究什么。

**提示词不是咒语，而是给 AI 员工写的一份工作交接单。** 备课搭子把这条交接单藏在一组选择题后面：老师做的是专业判断，工具负责把它组装成 AI 听得懂的结构。

## 功能特性

- **8 组引导式选择，不写一句提示词**：学段学科 → 课题课时 → 班级学情 → 研究要素 → 名师风格 → 输出格式 → 证据材料 → 白板平台，一路勾选即可；
- **学情按学科自动出题**：选择学科后，学情选项自动匹配该学科的典型学习困难（如数学的"分数概念抽象"、语文的"概括能力弱"），另有"口述补充"自由填写；
- **内置六个课堂研究杠杆**：情境创设 / 问题设计 / 小组合作 / 表达倾听 / 交流反思 / 当堂检测，可另选"其他（自填）"；
- **名师风格池（可选加分项）**：按学段×学科匹配公开教学名家（于永正、窦桂梅等），附课例视频搜索入口（国家智慧教育平台 / B 站 / 百度），也可自填风格描述或跳过；
- **输出 REAL 四要素结构**：R（角色）· E（证据：课题＋学情＋材料）· A（行动：交付什么）· L（限制：标准、格式、边界、脱敏要求）；
- **双内置教学设计模板**：简化版（十章节＋四附录，不含思维结构与教学反思，轻便快捷）与完整版（十二章节＋四附录，含「课堂教学思维结构」——上课的"施工蓝图"，双轨输出：WorkBuddy 等智能体直接渲染为向右逻辑图嵌入 Word 文档（图下自带修改规则：编辑文末「课堂教学思维结构」图源码，发回智能体即可重新出图），纯文本模型输出 MD 代码块可导入 XMind 生成；每环节有预估用时、含若干"教学行为对"、重难点环节附认知障碍及解决对策、标明各环节检测的教学目标，体现"教学评一致性"），教学反思为成长型思维轻量设计（满意之处→归因＋保持与迁移／没做好的→归因＋对策行动，"每天几分钟，成长很轻松"）；另可粘贴校本模板结构；
- **自动生成自检清单**：提示词生成后自动核验关键项是否齐全，缺什么一眼可见；
- **一键复制全文**：粘贴到任何大模型即可使用，工具与平台无关。建议直接发给WorkBuddy等智能体，要求直接生成可下载的Word文档即可。

## 快速开始

1. 下载 `index.html`（本仓库唯一需要的文件）；
2. **双击打开**——不需要安装、不需要联网、不需要登录；
3. 按页面引导完成选择，点击"**生成备课提示词**"；
4. 点击"**复制全文**"，粘贴到您常用的大模型对话框，发送；
5. 拿到初稿后用"**三问验收**"：①能用吗？②AI 做对了什么？③我还要改什么？再决定 0—5 轮追问优化。

> 最短可用路径：学段学科 → 课题课时 → 三项核心学情 → 一个研究要素 → 生成。其余选项都是加分项，可跳过。
>
> 课程标准不用上传（智能体自行检索现行版本核对引用）；但**教材照片必须随提示词一并上传**（网络无可靠电子版）。您需要提供的只有三样：课题 ＋ 班级学情 ＋ 教材照片。

## 使用场景

- 教师日常备课：快速获得贴合本班学情的教学设计初稿；
- 集体备课：备课组长用统一框架组织共备，提示词即讨论底稿；
- 教研活动：围绕同一课题比较"自然提问 vs REAL 提示词"的输出差异；
- 教师培训：作为人机协同备课的实操载体（已在多所学校骨干教师培训中现场使用）。

## 样例：课堂教学思维结构长什么样

完整版模板生成的第八部分「课堂教学思维结构」，是一节课的"施工蓝图"。以下为初中历史《丝绸之路的开通与经营西域》的真实样例（WorkBuddy 等智能体可直接渲染成图嵌入文档；纯文本路径为 MD 导入 XMind）：

```markdown
# 丝绸之路的开通与经营西域

## 环节一：展示史料引入新课（2min）

### 教师活动
- 展示《史记·大宛列传》史料

### 学生活动
- 推出张骞出使西域的动机，引入新课

## 环节二：图示分析凿空之举（13min）

### 教师活动
- 结合《张骞第一次出使西域路线图》，描述信息
- 通过评价张骞向学生示范如何评价历史人物
- 提问：为什么说张骞出使西域是"凿空"之举？

### 学生活动
- 完成表格填空
- 观察和学习评价历史人物的方式
- 结合地图谈认识

## 环节三：分析中央对西域的管理（8min·检测目标1、3）

### 认知障碍
- 难以同时认识到：汉朝对西域的经营既是对统一多民族国家的巩固，也保障了丝绸之路的畅通

### 解决对策
- 结合多种地图与表格，引导学生循序渐进深化理解

### 教师活动
- 展示《西汉形势图》，介绍西域的地理概念
- 请学生从不同视角思考汉朝对西域管理的影响
- 展示《后汉书》中班超的史料，请学生模仿评价张骞的方式评价班超
- 展示《秦朝形势图》《西汉形势图》《东汉形势图》，请学生谈谈认识

### 学生活动
- 结合教材内容，完成表格填空
- 从不同视角分析汉朝对西域管理的影响
- 结合史料对班超进行评价
- 结合地图进行分析

## 环节四：结合史料分析丝绸之路（15min·检测目标2、3）

### 教师活动
- 展示《丝绸之路图》及相关史料
- 提供丝绸之路学习单
- 提问：请分视角谈谈对丝绸之路的认识

### 学生活动
- 结合地图描述陆上丝绸之路的基本路线
- 分析史料的价值
- 独立完成学习单并小组交流讨论

## 环节五：课堂小结（2min·回扣目标）

### 教师总结
- 梳理知识结构，回扣导入情境
```

## 设计特色：成长型思维教学反思（每天几分钟，成长很轻松）

完整版模板的第十二部分不是普通的"课后小结"，而是一套**轻量级的成长型思维训练装置**——不让老师写长反思，只填两张表：

**表一「😊 这堂课的满意之处」**
> 怕什么真理无穷，进一寸有进一寸的欢喜。

| 序号 | 现象 | 归因 | 怎样保持？向哪儿迁移？ |
|---|---|---|---|
| 1 | （课后填） | （课后填） | （课后填） |

**表二「🤔 这堂课中，我还没做好的……」**
> 只要不变成习惯，失败是件好事。

| 序号 | 现象 | 归因 | 对策或行动 |
|---|---|---|---|
| 1 | （课后填） | （课后填） | （课后填） |

设计逻辑：**优点要归因并迁移**（把一次成功变成可复用的经验），**问题要归因并改进**（把一次失误变成下一步行动）。AI 只输出表格结构、引语与空行，绝不编造课堂效果——反思的内容永远属于上课的老师。每张表 2—3 行，课后几分钟填完，不给老师增负，却在日积月累中养成"归因而非归因于天赋"的成长型思维。

## 隐私与使用边界

- **完全本地运行**：工具不联网、不收集任何数据，您的填写内容只存在于自己的浏览器里；
- **请自觉脱敏**：不要把学生姓名、联系方式、完整成绩表等敏感信息写入任何字段；
- AI 生成的是**初稿**，不是定稿——最终的教学判断永远由教师作出。
